# grist-dkt-widgets

Grist custom widgets for the DKT DRP project.

## Widgets

- `dkt-summary-v2/` — DKT proposed-orders summary widget for `SaidaDados_ProjecaoEstoque`.

## DKT summary v2

Expected Grist fields include `id_produto`, `periodo`, `ano_mes`, `descricao`, `fornecedor`, `categoria`, `abc_index`, `custo`, `lote`, `flag_validate`, `proposta_pedido_qtd`, `proposta_pedido_qtd_mil`, `vlr_custo_proposta_pedido_qtd`, `lead_time_meses`, `ultimo_periodo_possivel_pedido`, `versao_plano`, and `ciclo`.
